# Ocean Voyager Build 0.5.6

This patched package includes the Build 0.5.6 quick-review outputs and visualization notes.

## Visualization convention
- Thermal recognition events use hollow circles.
- Yellow / orange / red hollow circles indicate weak / medium / strong thermal recognition.
- Visual first-seen events use filled purple diamonds.
- Confirmed waste uses a green check.
- Rejected object / seaweed uses a red cross.
- Animations include a bottom timeline strip showing thermal, visual, and final-decision event timing.
